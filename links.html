1. HTML Links

The <a> tag is used to create hyperlinks. Links help users move from one page to another.

Example:

Visit Google 
<a href="https://www.google.com">
    Visit Google
</a>

Important attributes:

  • href - specifies the link destination.
  • target - specifies where to open the link.
  • title - gives extra information about the link.

2. Open Link in New Tab

The target attribute can open a website in a new tab.

Open Wikipedia 
<a href="https://www.wikipedia.org"
target="_blank" rel="noopener">
    Open Wikipedia
</a>

3. HTML Images

The <img> tag is used to display pictures on a webpage. 

<img src="images/example.jpg"
alt="Example picture" width="300">

Important attributes:

  • src - image location.
  • alt - alternative text if image cannot load.
  • width - image width.
  • height - image height.

Note: Add a picture named example.jpg inside your images folder to display it.

4. Email Links

We can also create links that open an email application.

Send an Email 
<a href="mailto:example@gmail.com">
    Send an Email
</a>

5. Link to Another Page

HTML links can connect different pages inside the same website.

Go to Text Tags Page 
<a href="text.html">
    Go to Text Page
</a>

6. Link to a Video

We can use a link to open a video file.

Open Sample Video 
<a href="images/sample.mp4">
    Open Sample Video
</a>

7. Link to an Audio File

We can also create a link to an audio file.

Listen to Audio 
<a href="images/sample.mp3">
    Listen to Audio
</a>
