What is HTML?

HTML is the basic language of web development. It helps us organize text, images, links, tables, forms and other content on a webpage.

Why do we use HTML?

  • To create web pages.
  • To add text and images.
  • To create links between pages.
  • To make forms and tables.
  • To organize website content.

Basic HTML Structure

Every HTML page has a basic structure like this:

<!DOCTYPE html>
<html>
<head>
    <title>My First Website</title>
</head>

<body>
    <h1>Hello World!</h1>
    <p>This is my first webpage.</p>
</body>

</html>
