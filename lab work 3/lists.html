1. What are HTML Lists?

HTML lists are used to display information in an organized way. We can use lists for names, steps, items and many other things.

2. Ordered List

The <ol> tag creates a numbered list. Each item is written using the <li> tag.

Example:

  1. Open Visual Studio Code
  2. Create an HTML file
  3. Write HTML code
  4. Save the file
<ol>
    <li>Open VS Code</li>
    <li>Create HTML file</li>
    <li>Write code</li>
</ol>

Attributes:

  • type - changes the numbering style (1, A, a, I, i).
  • start - sets the starting number.
  • reversed - makes the numbering go backwards.

Different numbering:

  1. Apple
  2. Banana
  3. Orange

3. Unordered List

The <ul> tag creates a list with bullet points.

Example:

  • HTML
  • CSS
  • JavaScript
  • Bootstrap
<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

Attributes:

The type attribute was used in older HTML to change bullet styles. Today, CSS list-style-type is preferred.

Example with CSS-style bullets:

  • Red
  • Blue
  • Green

4. Description List

The <dl> tag creates a description list. The <dt> tag gives the term and the <dd> tag gives its description.

Example:

HTML
Language used to create web pages.
CSS
Language used to style web pages.
JavaScript
Language used to add interactivity.
<dl>
    <dt>HTML</dt>
    <dd>Creates web pages</dd>

    <dt>CSS</dt>
    <dd>Styles web pages</dd>
</dl>

Attributes: Global attributes like id and class.

5. Nested Lists

A nested list is a list inside another list.

  • Frontend
    • HTML
    • CSS
  • Programming
    • Python
    • JavaScript
<ul>
    <li>Frontend
        <ul>
            <li>HTML</li>
            <li>CSS</li>
        </ul>
    </li>
</ul>
