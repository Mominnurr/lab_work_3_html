1. What is Multimedia in HTML?

Multimedia means adding different types of content to a website, such as pictures, sounds and videos. HTML has special tags for displaying these files.

2. Images

The <img> tag is used to display images on a webpage. 

<img src="images/example.jpg"
alt="Example image" width="300">

Important attributes:

  • src - tells the browser where the image is located.
  • alt - describes the image.
  • width - sets the image width.
  • height - sets the image height.

Note: Put an image named example.jpg inside the images folder.

3. Audio

The <audio> tag is used to play sound files on a webpage. 

<audio controls>
    <source src="images/sample.mp3"
    type="audio/mpeg">
</audio>

Important attributes:

  • controls - displays audio controls.
  • autoplay - tries to play audio automatically.
  • loop - repeats the audio.
  • muted - starts the audio muted.

4. Video

The <video> tag is used to show video files on a webpage. 

<video width="400" controls>
    <source src="images/sample.mp4"
    type="video/mp4">
</video>

Important attributes:

  • controls - shows play and pause buttons.
  • width - sets the video width.
  • height - sets the video height.
  • poster - displays an image before video playback.
  • loop - repeats the video.

5. YouTube Video

We can also display a YouTube video using the <iframe> tag. 

<iframe
src="https://www.youtube.com/embed/VIDEO_ID"
width="400"
height="250">
</iframe>

6. Why is Multimedia Important?

  • Images make websites more attractive.
  • Audio can be used for music and recordings.
  • Videos help explain information.
  • Multimedia makes websites more interesting.
