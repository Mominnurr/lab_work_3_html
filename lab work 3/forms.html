1. What are HTML Forms?

HTML forms are used to collect information from website visitors. For example, a website can ask for a name, email and password.

2. Form Tag

The <form> tag is used to create a form. It contains different input fields and buttons. 

<form>
    Form elements go here
</form>

Important attributes:

  • action - specifies where form data is sent.
  • method - specifies how data is sent (GET or POST).
  • target - specifies where the response opens.

3. Text Input

The input type text is used to enter a name or other text.

<input type="text" placeholder="Your name">

4. Email Input

Email input is used to enter an email address.

<input type="email" placeholder="example@gmail.com">

5. Password Input

Password input hides the characters typed by the user.

<input type="password" placeholder="Enter password">

6. Radio Buttons

Radio buttons allow users to choose one option from a group.

Male Female 
<input type="radio" name="gender"> Male
<input type="radio" name="gender"> Female

7. Checkboxes

Checkboxes allow users to select multiple options.

HTML CSS JavaScript 
<input type="checkbox"> HTML
<input type="checkbox"> CSS

8. Select Dropdown

The select tag creates a dropdown menu.

<select>
    <option>HTML</option>
    <option>CSS</option>
</select>

9. Textarea

Textarea is used for longer messages or comments.

<textarea rows="4" cols="40">
</textarea>

10. Submit Button

The submit button sends form information.

<button type="submit">Submit</button>
