1. What are Semantic Tags?

Semantic HTML tags describe the meaning of the content inside them. They help browsers and developers understand the structure of a webpage.

2. Header Tag

The <header> tag is used for the top part of a webpage or a section. It usually contains a title or logo. 

<header>
    <h1>My Website</h1>
    <p>Welcome to my page</p>
</header>

3. Navigation Tag

The <nav> tag contains navigation links that help users move between pages. 

<nav>
    <a href="index.html">Home</a>
    <a href="about.html">About</a>
</nav>

4. Main Tag

The <main> tag contains the main content of a webpage. A page should normally have only one main element. 

<main>
    <h2>Main Content</h2>
    <p>This is the main part.</p>
</main>

5. Section Tag

The <section> tag groups related content together. It usually has a heading. 

<section>
    <h2>About Us</h2>
    <p>Information about our website.</p>
</section>

6. Article Tag

The <article> tag contains independent content, such as a blog post or news article. 

<article>
    <h2>My First Blog</h2>
    <p>This is a blog post.</p>
</article>

7. Aside Tag

The <aside> tag contains extra information related to the main content, such as side notes. 

<aside>
    <h3>Did you know?</h3>
    <p>HTML is used to create web pages.</p>
</aside>

8. Footer Tag

The <footer> tag is normally used at the bottom of a webpage. It can contain copyright information and contact details. 

<footer>
    <p>Copyright 2026</p>
</footer>

9. Div and Span Tags

The <div> tag groups content into a block. The <span> tag groups a small part of text inside a line.

This is a Div Example

This whole box is inside a div.

HTML is very useful for making websites. 

<div>
    <p>This is a block.</p>
</div>

<span>This is inline text.</span>
