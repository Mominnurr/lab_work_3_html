1. What is Metadata?

Metadata is information about a webpage. It is written inside the <head> section of an HTML document.

Metadata is not normally displayed directly on the webpage. It helps browsers understand information about the website.

2. Head Tag

The <head> tag contains information about the HTML document, such as its title, character encoding and links to CSS files. 

<head>
    <title>My Website</title>
    <meta charset="UTF-8">
</head>

3. Title Tag

The <title> tag sets the title of the webpage. It appears in the browser tab. 

<title>My First Website</title>

4. Charset Attribute

The charset attribute defines the character encoding used by the webpage.

UTF-8 supports many languages and special characters. 

<meta charset="UTF-8">

5. Viewport Meta Tag

The viewport meta tag helps a website display correctly on mobile phones and different screen sizes. 

<meta name="viewport"
content="width=device-width, initial-scale=1.0">

6. Description Meta Tag

The description meta tag provides a short summary of the webpage. Search engines may use it in search results. 

<meta name="description"
content="Learn HTML tags and examples">

7. Keywords Meta Tag

The keywords meta tag describes words related to the content of a webpage. Modern search engines generally do not use it for ranking. 

<meta name="keywords"
content="HTML, CSS, website, learning">

8. Author Meta Tag

The author meta tag identifies the person who created the webpage. 

<meta name="author" content="Student">

9. Link Tag

The <link> tag connects an external file, such as a CSS stylesheet, to an HTML page. 

<link rel="stylesheet" href="css/style.css">

10. Complete Metadata Example

Here is an example of a complete head section:

<head>
    <title>HTML Learning Website</title>

    <meta charset="UTF-8">

    <meta name="viewport"
    content="width=device-width, initial-scale=1.0">

    <meta name="description"
    content="Learn HTML tags">

    <meta name="author" content="Student">

    <link rel="stylesheet"
    href="css/style.css">
</head>
