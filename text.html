1. Headings

HTML has six heading tags. They are used for titles and subtitles.

Tags: <h1> to <h6>

This is Heading 1

This is Heading 2

This is Heading 3

This is Heading 4

This is Heading 5
This is Heading 6
<h1>Main Heading</h1>
<h2>Sub Heading</h2>

Attributes: Global attributes such as id, class and style.

2. Paragraph Tag

The <p> tag is used to write paragraphs on a webpage.

This is an example paragraph.

<p>Hello, welcome to my website!</p>

Attributes: Global attributes like class and id.

3. Bold and Strong Tags

The <b> tag makes text bold.

This text is bold.

The <strong> tag shows important text.

This text is important. 
<b>Bold text</b>
<strong>Important text</strong>

4. Italic and Emphasis Tags

The <i> tag makes text italic.

This text is italic.

The <em> tag gives emphasis to text.

This text is emphasized. 
<i>Italic text</i>
<em>Emphasized text</em>

5. Underline Tag

The <u> tag underlines text.

This text is underlined. 
<u>Underlined text</u>

6. Mark Tag

The <mark> tag highlights text.

This is a highlighted word in a sentence.

<mark>Highlighted text</mark>

7. Small Tag

The <small> tag displays smaller text.

This is smaller text. 
<small>Small text</small>

8. Line Break and Horizontal Line

The <br> tag creates a new line.

Hello!
Welcome to HTML.

The <hr> tag creates a horizontal line.

Hello<br>World
<hr>
