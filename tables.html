1. What are HTML Tables?

HTML tables are used to display information in rows and columns. They are useful for showing student marks, prices and other data.

2. Main Table Tags

  • <table> - creates a table.
  • <tr> - creates a table row.
  • <th> - creates a heading cell.
  • <td> - creates a normal data cell.
  • <caption> - gives a title to the table.
  • <thead> - groups the heading rows.
  • <tbody> - groups the main table content.
  • <tfoot> - groups the footer rows.

3. Simple HTML Table

Here is an example of a student information table.

Name Age Course
Ali 20 IT
Madina 19 Computer Science
John 21 Software Engineering 
<table>
    <tr>
        <th>Name</th>
        <th>Age</th>
    </tr>

    <tr>
        <td>Ali</td>
        <td>20</td>
    </tr>
</table>

4. Table Attributes

Some important table cell attributes are:

  • colspan - makes a cell cover multiple columns.
  • rowspan - makes a cell cover multiple rows.

Colspan Example

<th colspan="2">Student Details</th>
